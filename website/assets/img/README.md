# Aset gambar lokal

Direktori ini disiapkan untuk gambar situs. Pengunduhan langsung ke server media lama `yayasankasihmulia.org/wp-content/uploads/` ditolak oleh server sumber (HTTP 403) ketika migrasi ini dilakukan. Karena itu file gambar biner belum dapat disalin ke sini dan referensi di HTML masih sementara menggunakan URL sumber.
